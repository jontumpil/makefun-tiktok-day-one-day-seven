A 36-second vertical TikTok video about Star Catcher, a tiny star-catching game my AI agent built: day one is one star and a score, day seven is the same map and the same start with combos, golden stars, bombs, particles and a magnet power-up — closing on the newer build being played, an invitation to start yours at make.fun, and make.fun's referral end card.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `VIDEO.json` — the TikTok address of the posted video — into the output directory. Replace the placeholder address in `VIDEO.json` with the real one after posting the video (see `CAPTION.txt` for the caption to post with it).
